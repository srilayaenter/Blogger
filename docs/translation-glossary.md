# Translation Glossary

Source of truth for the rule: `CLAUDE.md` §17. Tamil is the source language; this glossary
exists to keep ingredient and technique translations **consistent** across every recipe, not to
invent new terms.

## Rules

- English translations must be faithful, clear, natural, and suitable for a home cook.
- Do not add information not present in the Tamil source.
- Do not remove important cooking context.
- Do not guess unclear quantities.
- Do not replace a culturally specific ingredient with an incorrect equivalent.
- Do not translate the same Tamil ingredient inconsistently across recipes — always check this
  glossary first, and add new terms here as they're confirmed.
- If no exact English equivalent exists: preserve the Tamil term, add a short explanation only if
  verified, and never guess.

## Maintenance

This file is updated during the translation step of the Google Workspace review process (§9,
step 12): whenever a reviewer translates a Tamil term not yet listed here, add it as a new row
before marking `translation_status = approved` for that recipe. Entries are never removed, only
corrected, so historical recipes stay consistent with what was actually published.
